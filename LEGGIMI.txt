AURA POMPEI — Fish & Steak · Sito web
=====================================

COM'È FATTO
-----------
Sito statico (HTML + CSS + JavaScript puro). Nessun server, nessun backend.
Si pubblica così com'è su GitHub Pages, Netlify o qualsiasi hosting statico.

  index.html            → la pagina
  css/styles.css        → grafica
  js/data.js            → *** TUTTI I DATI: menù, prezzi, orari, contatti ***
  js/app.js             → logica (non serve toccarlo)
  assets/img/           → foto, logo, poster (WebP ottimizzati)
  assets/video/         → video di sfondo (mp4 + webm)

MODIFICARE MENÙ, PREZZI, ORARI, CONTATTI
----------------------------------------
Apri SOLO  js/data.js  con un editor di testo.
- Cambiare un prezzo: modifica il valore tra virgolette, es.  price: "18€"
- Aggiungere un piatto: copia una riga { name: ..., price: ... } e incollala.
- Orari: sezione "hours" (formato 24h). "Aperto ora" si aggiorna da solo.
- Telefono / WhatsApp / social / TheFork: sezione "business".
Salvi il file → il sito è aggiornato. Non serve toccare HTML o CSS.

PUBBLICARE SU GITHUB PAGES
--------------------------
1. Crea un repository e carica tutti questi file nella radice.
2. Settings → Pages → Branch: main / root → Save.
3. Il sito sarà online all'indirizzo che GitHub ti mostra.
   (Per il dominio aurapompei.it: Settings → Pages → Custom domain.)
